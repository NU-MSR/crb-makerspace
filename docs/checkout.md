# Tool Checkout

 It is generally preferred that you work in the Makerspace when using Makerspace equipment. If you need to borrow a tool, please ask management and fill out the following form (there is also a QR code by the door). When you return the tool, please let management know (in person or by email) and it will be marked as returned.
